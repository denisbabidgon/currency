Текстовые функции

CHAR_LENGTH() - длина строки
LOWER() - все буквы строчные
UPPER() - все буквы заглавные

LTRIM() - удаляет все пробельные символы в начале строки
RTRIM() - удаляет все пробельные символы в конце строки
TRIM() - удаляет все пробельные символы в начале и в конце строки

REVERSE() - переворачивает текст
REPEAT() - повторить что-то какое-то количество раз

LPAD(строку, финальная длина, символ заполнитель) - увеличить строку до определенного количества символов используя символ заполнитель
RPAD(строку, финальная длина, символ заполнитель) - увеличить строку до определенного количества символов используя символ заполнитель

LEFT() - извлекают из строки определенное кол-во символов
RIGHT() - извлекают из строки определенное кол-во символов

LOCATE() - возвращает положение подстроки в строке

REPLACE(извлекаемое поле, 'что меняем', 'на что меняем') - замена подстрок на подстроки

SUBSTRING(исходная строка, позиция извлекаемого элемента) - используется для извлечения подстроки из строки

ПЕРВИЧНЫЙ и ВНЕШНИЙ КЛЮЧи

1) поле не должно содержать значение NULL
2) поле должно быть уникальным


CREATE TABLE Books
(
    id          INT PRIMARY KEY AUTO_INCREMENT,
    title       VARCHAR(40),
    author_id   INT,
    FOREIGN KEY (author_id) REFERENCES Authors(id)
);



CREATE TABLE Authors
(
    id          INT PRIMARY KEY AUTO_INCREMENT,
    name        VARCHAR(40),
    surname     VARCHAR(40)
);
